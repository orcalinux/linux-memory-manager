\hypertarget{md_docs_2pages_2architecture_autotoc_md46}{}\doxysubsection{\texorpdfstring{Page Family System}{Page Family System}}\label{md_docs_2pages_2architecture_autotoc_md46}
Each registered data type gets its own {\bfseries{page family}}\+:


\begin{DoxyItemize}
\item Manages a set of 4KB virtual memory pages.
\item Each page is divided into fixed-\/size blocks for the registered structure.
\item Tracks free and used blocks within its pages.
\item Optimizes for minimal fragmentation by managing blocks of a single size.
\end{DoxyItemize}

\hypertarget{md_docs_2pages_2architecture_autotoc_md54}{}\doxysection{\texorpdfstring{GLThread Design}{GLThread Design}}\label{md_docs_2pages_2architecture_autotoc_md54}
GLThread is an {\bfseries{intrusive linked list}}. This means the list node is embedded directly within the data structure it belongs to, rather than being stored separately.

{\bfseries{Advantages\+:}}


\begin{DoxyItemize}
\item {\bfseries{Zero allocation overhead\+:}} No extra memory allocations are needed for list nodes.
\item {\bfseries{Cache-\/friendly\+:}} The list node and the data are in the same memory block, improving cache locality.
\item {\bfseries{Type-\/safe conversion\+:}} Macros provide a safe way to get the containing structure from a list node pointer.
\item {\bfseries{No pointer indirection\+:}} Accessing the data from the node is a simple offset calculation, not a pointer lookup.
\end{DoxyItemize}

\hypertarget{md_docs_2pages_2architecture_autotoc_md56}{}\doxysection{\texorpdfstring{Memory Allocation Flow}{Memory Allocation Flow}}\label{md_docs_2pages_2architecture_autotoc_md56}
The process of allocating and deallocating memory is central to the manager\textquotesingle{}s design.\hypertarget{md_docs_2pages_2architecture_autotoc_md57}{}\doxysubsection{\texorpdfstring{Allocation Process}{Allocation Process}}\label{md_docs_2pages_2architecture_autotoc_md57}
The following diagram illustrates the flow when {\ttfamily XCALLOC} is called\+:



{\bfseries{Steps\+:}}


\begin{DoxyEnumerate}
\item {\bfseries{Application calls {\ttfamily XCALLOC}\+:}}


\begin{DoxyCode}{0}
\DoxyCodeLine{Employee\ *emp\ =\ \mbox{\hyperlink{memory__manager__api_8h_a3a295a457410e0dd9a09f7dc73e3b78e}{XCALLOC}}(1,\ Employee);}

\end{DoxyCode}

\item {\bfseries{Find Page Family\+:}} The manager looks up the page family registered for the {\ttfamily Employee} struct.
\item {\bfseries{Check for Free Block\+:}} It checks the {\ttfamily free\+\_\+block\+\_\+priority\+\_\+list} for an available block.
\item {\bfseries{Two Paths\+:}}
\begin{DoxyItemize}
\item {\bfseries{✓ If a free block exists\+:}}
\begin{DoxyItemize}
\item The block is removed from the free list.
\item Its metadata is updated to mark it as {\ttfamily used}.
\item A pointer to the data portion of the block is returned to the application.
\end{DoxyItemize}
\item {\bfseries{✗ If no free block exists\+:}}
\begin{DoxyItemize}
\item A new 4KB page is requested from the kernel using {\ttfamily mmap()}.
\item The new page is initialized and divided into blocks of the appropriate size.
\item The first block is returned to the user, and the rest are added to the free list.
\end{DoxyItemize}
\end{DoxyItemize}
\end{DoxyEnumerate}

\hypertarget{md_docs_2pages_2architecture_autotoc_md59}{}\doxysubsection{\texorpdfstring{Deallocation Process}{Deallocation Process}}\label{md_docs_2pages_2architecture_autotoc_md59}

\begin{DoxyEnumerate}
\item {\bfseries{Application calls {\ttfamily XFREE}\+:}}


\begin{DoxyCode}{0}
\DoxyCodeLine{\mbox{\hyperlink{memory__manager__api_8h_a36a9e17ea9f866a838cf58da2834274a}{XFREE}}(emp);}

\end{DoxyCode}

\item {\bfseries{Find Block Metadata\+:}} The manager calculates the address of the block\textquotesingle{}s metadata from the given pointer.
\item {\bfseries{Mark as Free\+:}} The block\textquotesingle{}s {\ttfamily is\+\_\+free} flag is set to {\ttfamily true}.
\item {\bfseries{Add to Free List\+:}} The block is added back to the page family\textquotesingle{}s priority free list.
\item {\bfseries{Merge Blocks\+:}} The manager attempts to merge the newly freed block with adjacent free blocks to form a larger contiguous block.
\item {\bfseries{Return Page to Kernel\+:}} If a page becomes completely empty (all its blocks are free and merged into one), it can be returned to the kernel using {\ttfamily munmap()} to reduce the process\textquotesingle{}s memory footprint.
\end{DoxyEnumerate}

\hypertarget{md_docs_2pages_2architecture_autotoc_md62}{}\doxysubsection{\texorpdfstring{Priority Free Lists}{Priority Free Lists}}\label{md_docs_2pages_2architecture_autotoc_md62}

\begin{DoxyItemize}
\item Free blocks are kept in a priority-\/ordered list, with the largest blocks first.
\item Reduces fragmentation and improves allocation speed.
\end{DoxyItemize}\hypertarget{md_docs_2pages_2architecture_autotoc_md63}{}\doxysubsection{\texorpdfstring{Block Merging}{Block Merging}}\label{md_docs_2pages_2architecture_autotoc_md63}

\begin{DoxyItemize}
\item Adjacent free blocks are merged into one larger block when possible.
\item Reduces fragmentation and increases allocation success rate for larger structures.
\end{DoxyItemize}\hypertarget{md_docs_2pages_2architecture_autotoc_md64}{}\doxysubsection{\texorpdfstring{Page Recycling}{Page Recycling}}\label{md_docs_2pages_2architecture_autotoc_md64}

\begin{DoxyItemize}
\item Completely free pages are unmapped using {\ttfamily munmap()}.
\item Keeps memory footprint dynamic and efficient.
\end{DoxyItemize}

\hypertarget{md_docs_2pages_2architecture_autotoc_md66}{}\doxysection{\texorpdfstring{Thread Safety Considerations}{Thread Safety Considerations}}\label{md_docs_2pages_2architecture_autotoc_md66}
{\bfseries{Current Implementation\+:}}


\begin{DoxyItemize}
\item GLThread operations are thread-\/safe.
\item Memory allocation ({\ttfamily XCALLOC}, {\ttfamily XFREE}) is not thread-\/safe.
\end{DoxyItemize}

{\bfseries{Recommendations for multi-\/threaded use\+:}}


\begin{DoxyItemize}
\item Use a mutex for global synchronization.
\item Create per-\/thread page families or memory managers.
\item Apply fine-\/grained locking at the page-\/family level for concurrency.
\end{DoxyItemize}
