\hypertarget{md_docs_2pages_2developer__guide_autotoc_md84}{}\doxysubsection{\texorpdfstring{Core Components}{Core Components}}\label{md_docs_2pages_2developer__guide_autotoc_md84}
The memory manager consists of several key components\+:


\begin{DoxyEnumerate}
\item {\bfseries{VM Page Manager}} (\doxylink{memory__manager_8c}{memory\+\_\+manager.\+c})
\begin{DoxyItemize}
\item Manages virtual memory pages from the kernel
\item Implements page families for different data types
\item Handles page allocation and deallocation
\end{DoxyItemize}
\item {\bfseries{Block Allocator}} (\doxylink{memory__manager_8c}{memory\+\_\+manager.\+c})
\begin{DoxyItemize}
\item Divides pages into fixed-\/size blocks
\item Maintains free block lists
\item Implements block splitting and merging
\end{DoxyItemize}
\item {\bfseries{GLThread}} (\doxylink{glthread_8c}{glthread.\+c})
\begin{DoxyItemize}
\item Generic intrusive linked list
\item Thread-\/safe operations
\item Zero-\/overhead abstraction
\end{DoxyItemize}
\item {\bfseries{Type Registry}} (\doxylink{datatype__size__lookup_8c}{datatype\+\_\+size\+\_\+lookup.\+c})
\begin{DoxyItemize}
\item Maps type names to sizes
\item Enables dynamic type registration
\item Used by XCALLOC/\+XFREE macros
\end{DoxyItemize}
\end{DoxyEnumerate}\hypertarget{md_docs_2pages_2developer__guide_autotoc_md85}{}\doxysubsection{\texorpdfstring{Memory Model}{Memory Model}}\label{md_docs_2pages_2developer__guide_autotoc_md85}
