A compact, production-\/oriented Heap Memory Manager (HMM) for Linux. This project provides a custom allocator, a thread-\/safe intrusive linked list implementation (GLThread), and comprehensive documentation and tests to aid integration and development.\hypertarget{index_autotoc_md225}{}\doxysection{\texorpdfstring{Highlights}{Highlights}}\label{index_autotoc_md225}

\begin{DoxyItemize}
\item High-\/performance, low-\/fragmentation heap allocator
\item Intrusive, thread-\/safe linked-\/list primitives (GLThread)
\item Comprehensive API and developer documentation (Doxygen)
\item Test suite and build targets for static/shared libraries
\end{DoxyItemize}\hypertarget{index_autotoc_md226}{}\doxysection{\texorpdfstring{Quick start}{Quick start}}\label{index_autotoc_md226}
Prerequisites\+: GCC, GNU Make, and (optionally) Doxygen.

\begin{DoxyCode}{0}

\end{DoxyCode}

\begin{DoxyCode}{0}

\end{DoxyCode}


Run tests / example binary\+:
