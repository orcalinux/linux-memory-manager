{\bfseries{Problem\+:}} Segmentation fault

{\bfseries{Solution\+:}}


\begin{DoxyItemize}
\item Did you call \doxylink{memory__manager__api_8h_a0d0d58e2b3f34ada92ab7889d013e717}{mm\+\_\+init()}?
\item Did you register your structure with \doxylink{memory__manager__api_8h_a499d5d9d246e2afe4506e751ba45ec1e}{MM\+\_\+\+REG\+\_\+\+STRUCT()}?
\item Are you freeing memory twice?
\end{DoxyItemize}

{\bfseries{Problem\+:}} Memory leaks

{\bfseries{Solution\+:}} Use \doxylink{memory__manager__api_8h_a0107300bfc4db599504abef54c980fa6}{mm\+\_\+print\+\_\+memory\+\_\+usage()} to track allocations and ensure all \doxylink{memory__manager__api_8h_a3a295a457410e0dd9a09f7dc73e3b78e}{XCALLOC()} calls have matching \doxylink{memory__manager__api_8h_a36a9e17ea9f866a838cf58da2834274a}{XFREE()} calls.
